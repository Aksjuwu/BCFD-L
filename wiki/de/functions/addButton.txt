<dash>
name: $addButton
desc: Fügt eine Schaltfläche (Button) zur erstellten Nachricht oder über ihre ID zu einer zuvor gesendeten Nachricht hinzu.
category: Komponenten

<block type="text" title="Wie funktioniert der Befehl?">
text: $addButton fügt pro Aufruf eine Schaltfläche hinzu. Sie können den Schaltflächentyp (Link oder interaktiv), den Stil, den Zustand (aktiviert/deaktiviert) und die Position (gleiche Zeile oder neue Zeile) steuern.
</block>

<block type="code" title="Syntax">
text: $addButton[newLine; ID/URL; label; style; (disabled; emoji; messageID)]
</block>

<block type="code" title="Kopierfertiges Beispiel">
text: $addButton[no; btn_confirm; Confirm; success]
</block>

<block type="options" title="Schaltflächenstile (style)">
option: primary|Blauer Button (Standardfarbe)
option: secondary|Grauer Button
option: success|Grüner Button
option: danger|Roter Button
option: link|Externer Link-Button (keine custom_id, löst keine Bot-Interaktion aus)
</block>

<block type="callout" kind="note">
text: Bei style = link muss das zweite Argument (ID/URL) eine vollständige URL sein, die mit http:// oder https:// beginnt.
</block>

<block type="callout" kind="warning">
text: Maximal 25 Schaltflächen pro Nachricht (5 Zeilen × 5 Schaltflächen pro Zeile). Wenn die aktuelle Zeile voll ist, wechselt die Schaltfläche automatisch in eine neue Zeile.
</block>
</dash>

<details>
syntax: $addButton[newLine; ID/URL; label; style; (disabled; emoji; messageID)]
param: newLine|yes/no|Erforderlich|Beginnt die Schaltfläche in einer neuen Zeile? yes = neue Zeile, no = gleiche Zeile neben der letzten Schaltfläche
param: ID/URL|text|Erforderlich|Benutzerdefinierte ID für die interaktive Schaltfläche oder eine vollständige URL, wenn style = link
param: label|text|Darf leer gelassen werden|Der auf der Schaltfläche angezeigte Text
param: style|text|Erforderlich|primary / secondary / success / danger / link
param: disabled|yes/no|Optional|yes zum Deaktivieren der Schaltfläche (Standard: no)
param: emoji|text|Optional|Ein Emoji, das in der Schaltfläche angezeigt werden soll
param: messageID|snowflake|Optional|ID einer zuvor gesendeten Bot-Nachricht, der die Schaltfläche anstelle der aktuellen Nachricht hinzugefügt werden soll
</details>
