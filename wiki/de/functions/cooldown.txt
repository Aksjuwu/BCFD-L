<dash>
name: $cooldown
desc: Verhindert, dass ein Benutzer das Skript für eine bestimmte Dauer erneut ausführt.
category: Zugriffskontrolle

<block type="text" title="Wie funktioniert der Befehl?">
text: $cooldown legt eine zeitbasierte Einschränkung pro Benutzer und pro Skript fest. Wenn der Benutzer versucht, dasselbe Skript erneut auszuführen, bevor die Abklingzeit abgelaufen ist, wird die angegebene Fehlermeldung angezeigt (mit verbleibender Zeit) und die Ausführung abgebrochen.
</block>

<block type="code" title="Syntax">
text: $cooldown[time; error message]
</block>

<block type="code" title="Kopierfertiges Beispiel">
text: $cooldown[10s; Please wait {time} before using this again!]
</block>

<block type="callout" kind="note">
text: Das Zeitformat verwendet: s (Sekunden), m (Minuten), h (Stunden), d (Tage). Verwenden Sie {time} oder %time% in der Fehlermeldung, um die verbleibende Abklingzeit anzuzeigen.
</block>
</dash>

<details>
syntax: $cooldown[time; error message]
param: time|text|Erforderlich|Dauer, bevor der Benutzer das Skript erneut ausführen kann. Format: Zahl + Einheit (s/m/h/d), z. B. 10s, 5m, 1h, 1d
param: error message|text|Erforderlich|Nachricht, die an den Benutzer gesendet wird, wenn die Abklingzeit aktiv ist. Verwenden Sie {time} oder %time%, um die verbleibende Zeit anzuzeigen.
</details>
