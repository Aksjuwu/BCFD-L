<dash>
name: $findRole
desc: Findet eine Rolle anhand von Name, ID oder Erwähnung und gibt deren Rollen-ID zurück.
category: Werkzeug

<block type="text" title="Wie funktioniert der Befehl?">
text: $findRole sucht im aktuellen Server anhand einer Rollenerwähnung, einer numerischen Rollen-ID oder eines Rollennamens (die Namenssuche ist unabhängig von Groß-/Kleinschreibung) nach einer Rolle. Es gibt die ID der Rolle zurück. Allein verwendet, wird die ID in den Kanal gesendet; inline verwendet, wird die ID direkt in den umgebenden Text eingesetzt.
</block>

<block type="code" title="Syntax">
text: $findRole[name]
text: $findRole[roleID]
text: $findRole[@role]
</block>

<block type="code" title="Kopierfertiges Beispiel">
text: $findRole[Moderators]
</block>

<block type="callout" kind="note">
text: Dieser Befehl kann nur innerhalb eines Servers verwendet werden. Wenn keine Rolle gefunden wird, wird ein Fehler zurückgegeben.
</block>
</dash>

<details>
syntax: $findRole[query]
param: Abfrage|text|Erforderlich|Eine Rollenerwähnung, eine Rollen-ID oder ein Rollenname, nach dem gesucht werden soll (unabhängig von Groß-/Kleinschreibung)
</details>
