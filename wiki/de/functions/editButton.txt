<dash>
name: $editButton
desc: Bearbeitet die Eigenschaften einer vorhandenen Schaltfläche auf einer Nachricht.
category: Komponenten

<block type="text" title="Wie funktioniert der Befehl?">
text: $editButton findet eine Schaltfläche auf einer Nachricht anhand ihrer ID oder URL und aktualisiert deren Beschriftung, Stil, deaktivierten Zustand und/oder Emoji. Es kann Schaltflächen auf einer ausstehenden View, einer Interaktions-Quellnachricht oder einer bestimmten Nachricht anhand ihrer ID ansprechen.
</block>

<block type="code" title="Syntax">
text: $editButton[ID/URL; label; style; (disabled; emoji; messageID)]
</block>

<block type="code" title="Kopierfertiges Beispiel">
text: $editButton[btn_confirm; Confirmed; success]
</block>

<block type="callout" kind="note">
text: Wenn messageID angegeben ist, ruft der Bot genau diese Nachricht ab und bearbeitet die Schaltfläche darauf. Andernfalls durchsucht er zuerst die ausstehende View, dann die Interaktions-Quellnachricht und zuletzt die letzte vom Bot gesendete Nachricht.
</block>

<block type="callout" kind="warning">
text: Die Zielnachricht muss von diesem Bot gesendet worden sein. Die Schaltfläche muss bereits mit der angegebenen ID oder URL auf der Nachricht vorhanden sein.
</block>
</dash>

<details>
syntax: $editButton[ID/URL; label; style; (disabled; emoji; messageID)]
param: ID/URL|text|Erforderlich|Die benutzerdefinierte ID oder URL der zu bearbeitenden Schaltfläche
param: label|text|Erforderlich|Der neue Text, der auf der Schaltfläche angezeigt werden soll
param: style|text|Erforderlich|primary / secondary / success / danger / link
param: disabled|yes/no|Optional|yes, um die Schaltfläche zu deaktivieren, no, um sie zu aktivieren
param: emoji|text|Optional|Neues Emoji, das innerhalb der Schaltfläche angezeigt werden soll
param: messageID|snowflake|Optional|ID einer bestimmten Bot-Nachricht, auf der die Schaltfläche bearbeitet werden soll
</details>
