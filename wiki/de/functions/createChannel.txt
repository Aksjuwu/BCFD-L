<dash>
name: $createChannel
desc: Erstellt einen neuen Kanal im Server.
category: Kanalverwaltung

<block type="text" title="Wie funktioniert der Befehl?">
text: $createChannel erstellt einen neuen Kanal im Server mit dem angegebenen Namen und Typ. Unterstützt werden Text-, Sprach-, Kategorie-, Forum- und Bühnenkanaltypen. Optional kann eine Kategorie-ID angegeben werden, um den Kanal unter eine bestimmte Kategorie zu legen. Der Bot muss über die Berechtigung "Kanäle verwalten" verfügen.
</block>

<block type="code" title="Syntax">
text: $createChannel[name; type; (category ID)]
</block>

<block type="code" title="Kopierfertiges Beispiel">
text: $createChannel[my-channel; text]
</block>

<block type="callout" kind="warning">
text: Der Bot muss über die Berechtigung "Kanäle verwalten" verfügen. Unterstützte Typen: text, voice, category, forum, stage.
</block>

<block type="callout" kind="note">
text: Die Kategorie-ID ist optional. Wenn sie angegeben wird, wird der neue Kanal unter dieser Kategorie erstellt.
</block>
</dash>

<details>
syntax: $createChannel[name; type; (category ID)]
param: name|text|Erforderlich|Der Name des neuen Kanals.
param: type|text|Erforderlich|Der Kanaltyp: text, voice, category, forum oder stage.
param: categoryID|text|Optional|Die ID der Kategorie, unter der der Kanal erstellt werden soll.
</details>
