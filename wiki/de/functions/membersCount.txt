<dash>
name: $membersCount
desc: Gibt die Anzahl der Mitglieder in einem Server zurück.
category: Info

<block type="text" title="Wie funktioniert der Befehl?">
text: Wenn $membersCount ohne Argumente aufgerufen wird, zählt der Bot alle menschlichen Nicht-Bot-Mitglieder im aktuellen Server und sendet die Anzahl. Wird es mit einer Server-ID und einem Ja/Nein-Flag aufgerufen, zählt es die Mitglieder in diesem bestimmten Server und schließt optional Bots ein.
</block>

<block type="code" title="Syntax">
text: $membersCount
text: $membersCount[guildID; includeBots]
</block>

<block type="code" title="Kopierfertiges Beispiel">
text: We have $membersCount members!
</block>

<block type="callout" kind="note">
text: Standardmäßig sind Bots von der Zählung ausgeschlossen. Um Bots einzuschließen, verwende $membersCount[guildID; yes]. Ohne Argumente funktioniert dieser Befehl nur innerhalb eines Servers. Bei Angabe einer Server-ID muss der Bot Mitglied dieses Servers sein.
</block>
</dash>

<details>
syntax: $membersCount[(guildID; includeBots)]
param: guildID|snowflake|Optional|Die ID eines anderen Servers, aus dem Mitglieder gezählt werden sollen. Wenn nicht angegeben, wird der aktuelle Server verwendet.
param: includeBots|yes/no|Optional|Setze auf "yes", um Bot-Konten in die Zählung einzubeziehen. Wenn nicht angegeben, werden nur menschliche Mitglieder gezählt.
</details>
