<dash>
name: $onLeave
desc: Ereignis, das ausgelöst wird, wenn ein Mitglied den Server verlässt.
category: Ereignis

<block type="text" title="Wie funktioniert das Ereignis?">
text: $onLeave ist ein Ereignis-Präfix, das ein FDScript auslöst, wann immer ein Mitglied den Server verlässt oder entfernt wird. Das Skript erhält die Informationen des austretenden Mitglieds. Optional kannst du in der ersten Zeile eine Kanal-ID angeben, um die Ausgabe an einen bestimmten Kanal zu lenken.
</block>

<block type="code" title="Syntax">
text: #PREFIX:$onLeave
</block>

<block type="code" title="Kopierfertiges Beispiel">
text: #PREFIX:$onLeave
 sendMessage[Goodbye $authorName!]
</block>

<block type="callout" kind="note">
text: Setze dies in die erste Zeile deiner FDScript-Datei. Das Skript wird automatisch ausgeführt, wenn ein Mitglied den Server verlässt.
</block>

<block type="callout" kind="important">
text: Dieses Ereignis wird im Ordner bot_events ausgeführt, nicht in bot_commands. Erstelle deine .fds-Datei dort.
</block>
</dash>
