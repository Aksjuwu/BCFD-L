<dash>
name: $findChannel
desc: Findet einen Kanal anhand von Name oder ID und gibt dessen ID zurück.
category: Kanal

<block type="text" title="Wie funktioniert der Befehl?">
text: $findChannel sucht im Server nach einem Kanal anhand von Name oder Erwähnung. Wenn eine Kanalerwähnung angegeben wird, wird geprüft, ob der Kanal existiert, und seine ID zurückgegeben. Wenn ein Kanalname angegeben wird, werden alle Serverkanäle unabhängig von Groß-/Kleinschreibung durchsucht und die ID des ersten Treffers zurückgegeben. Wenn nichts gefunden wird, wird eine leere Zeichenfolge zurückgegeben.
</block>

<block type="code" title="Syntax">
text: $findChannel[name/mention]
</block>

<block type="code" title="Kopierfertiges Beispiel">
text: $findChannel[general]
</block>

<block type="callout" kind="note">
text: Die Kanalnamenssuche ist unabhängig von Groß-/Kleinschreibung. Kann inline verwendet werden, um Kanalnamen dynamisch in IDs aufzulösen.
</block>
</dash>

<details>
syntax: $findChannel[name/mention/ID]
param: Kanal|text|Erforderlich|Ein Kanalname oder eine Erwähnung, nach der gesucht werden soll.
</details>
