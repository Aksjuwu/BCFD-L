<dash>
name: $removeButtons
desc: Удаляет все кнопки из сообщения или из ожидающего представления.
category: Компоненты

<block type="text" title="Как работает команда?">
text: При вызове $removeButtons без аргументов она удаляет все кнопки из ожидающего представления или из исходного сообщения взаимодействия. При вызове с ID сообщения она удаляет все кнопки из указанного сообщения бота.
</block>

<block type="code" title="Синтаксис">
text: $removeButtons
text: $removeButtons[(messageID)]
</block>

<block type="code" title="Пример для копирования">
text: $removeButtons[123456789012345678]
</block>

<block type="callout" kind="note">
text: ID сообщения должен указывать на сообщение, отправленное этим ботом. При вызове без аргументов сначала проверяется ожидающее представление, затем — исходное сообщение взаимодействия.
</block>
</dash>

<details>
syntax: $removeButtons[(messageID)]
param: messageID|snowflake|Optional|ID сообщения бота, из которого нужно удалить все кнопки. Если не указано, кнопки удаляются из ожидающего представления или из исходного сообщения взаимодействия.
</details>
