<dash>
name: $randomUserID
desc: Возвращает ID случайного участника-человека с сервера.
category: Случайность

<block type="text" title="Как работает команда?">
text: При вызове $randomUserID бот собирает всех участников, не являющихся ботами, на текущем сервере, выбирает одного случайным образом и отправляет его ID как необработанную числовую строку.
</block>

<block type="code" title="Синтаксис">
text: $randomUserID
</block>

<block type="code" title="Пример для копирования">
text: Random user ID: $randomUserID
</block>

<block type="callout" kind="note">
text: Эта команда работает только внутри сервера (не в личных сообщениях). Учётные записи ботов исключаются из пула выбора. Если участников-людей нет, команда завершится ошибкой.
</block>
</dash>
