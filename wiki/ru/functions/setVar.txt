<dash>
name: $setVar
desc: Сохраняет значение в постоянную переменную.
category: Переменные

<block type="text" title="Как работает команда?">
text: $setVar сохраняет значение под указанным именем переменной. С двумя аргументами сохраняется глобальная переменная. С тремя аргументами (имя, значение, ID пользователя) сохраняется переменная, специфичная для пользователя. Значения сохраняются после перезапусков бота.
</block>

<block type="code" title="Синтаксис">
text: $setVar[name; value]
</block>

<block type="code" title="Готовый пример для копирования">
text: $setVar[greeting; Hello World!]
</block>

<block type="callout" kind="note">
text: Переменные хранятся на диске и переживают перезапуски бота. Для извлечения сохранённых значений используйте $getVar. $setVar нельзя использовать внутри текста (как плейсхолдер).
</block>
</dash>

<details>
syntax: $setVar[name; value; (userID)]
param: name|text|Required|Имя переменной, под которым сохраняется значение
param: value|text|Required|Сохраняемое значение
param: userID|snowflake|Optional|Если указан, значение сохраняется как специфичное для пользователя, а не глобальное
</details>
