<dash>
name: $returnGuildChannelsID
desc: Collecte les IDs des canaux d'un serveur par type et les stocke pour une récupération ultérieure.
category: Commandes de retour

<block type="text" title="Comment fonctionne la commande ?">
text: $returnGuildChannelsID collecte tous les IDs des canaux d'un type spécifié dans un serveur donné et les stocke sous un nom de variable. Le résultat peut être récupéré plus tard avec $return[variableName]. Vous pouvez filtrer par type de canal tel que texte, vocal, catégorie, forum, stage, ou obtenir tous les canaux.
</block>

<block type="code" title="Syntaxe">
text: $returnGuildChannelsID[GuildID; ChannelType; var; separator]
</block>

<block type="code" title="Exemple prêt à copier">
text: $returnGuildChannelsID[$guildID; text; channelIDs; ,]
$sendMessage[Text channels: $return[channelIDs]]
</block>

<block type="options" title="Types de canaux">
option: all|Tous les types de canaux
option: text|Canaux texte uniquement
option: voice|Canaux vocaux uniquement
option: category|Canaux de catégorie uniquement
option: forum|Canaux forum uniquement
option: stage|Canaux de stage uniquement
</block>

<block type="callout" kind="note">
text: Le bot doit être membre du serveur cible. Utilisez $return[variableName] pour récupérer les IDs stockés après l'exécution. Le séparateur définit comment les IDs multiples sont joints (ex. : , ou ; ou espace).
</block>
</dash>

<details>
syntax: $returnGuildChannelsID[GuildID; ChannelType; var; separator]
param: GuildID|snowflake|Requis|L'ID du serveur dont il faut collecter les canaux
param: ChannelType|text|Requis|Le type de canaux à collecter : all, text, voice, category, forum ou stage
param: var|text|Requis|Le nom de la variable dans laquelle stocker le résultat (à utiliser avec $return[])
param: separator|text|Requis|Le séparateur entre les IDs multiples (ex. : , ou ;). Vous pouvez utiliser des séparateurs nommés : dot, com, apo, sem, colon
</details>
