<dash>
name: $editButton
desc: Modifie les propriétés d'un bouton existant sur un message.
category: Composants

<block type="text" title="Comment fonctionne la commande ?">
text: $editButton recherche un bouton par son ID ou son URL sur un message et met à jour son libellé, son style, son état désactivé et/ou son emoji. Il peut cibler des boutons sur une vue en attente, un message source d'interaction ou un message spécifique par ID.
</block>

<block type="code" title="Syntaxe">
text: $editButton[ID/URL; label; style; (disabled; emoji; messageID)]
</block>

<block type="code" title="Exemple prêt à copier">
text: $editButton[btn_confirm; Confirmed; success]
</block>

<block type="callout" kind="note">
text: Si messageID est fourni, le bot récupère ce message spécifique et modifie le bouton dessus. Sinon, il recherche dans la vue en attente, puis dans le message source de l'interaction, puis dans le dernier message envoyé par le bot.
</block>

<block type="callout" kind="warning">
text: Le message cible doit avoir été envoyé par ce bot. Le bouton doit déjà exister sur le message avec l'ID ou l'URL donné.
</block>
</dash>

<details>
syntax: $editButton[ID/URL; label; style; (disabled; emoji; messageID)]
param: ID/URL|text|Requis|L'ID personnalisé ou l'URL du bouton à modifier
param: label|text|Requis|Le nouveau texte à afficher sur le bouton
param: style|text|Requis|primary / secondary / success / danger / link
param: disabled|yes/no|Optionnel|yes pour désactiver le bouton, no pour l'activer
param: emoji|text|Optionnel|Nouvel emoji à afficher à l'intérieur du bouton
param: messageID|snowflake|Optionnel|ID d'un message spécifique du bot sur lequel modifier le bouton
</details>
