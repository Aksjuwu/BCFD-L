<dash>
name: $onlyIf
desc: Évalue une condition et interrompt le script si la condition est fausse.
category: Contrôle d'accès

<block type="text" title="Comment fonctionne la commande ?">
text: $onlyIf évalue une condition. Si la condition est vraie, le script continue normalement. Si elle est fausse, le message d'erreur fourni est affiché et le script est immédiatement interrompu.
</block>

<block type="code" title="Syntaxe">
text: $onlyIf[condition; error message]
</block>

<block type="code" title="Exemple prêt à copier">
text: $onlyIf[$authorID == 123456789; You are not authorized!]
</block>

<block type="callout" kind="note">
text: C'est plus strict que $if — il ne se contente pas de sauter le code, il arrête complètement tout le script. Utilisez-le pour les vérifications de contrôle d'accès qui doivent réussir pour que le script s'exécute.
</block>
</dash>

<details>
syntax: $onlyIf[condition; error message]
param: condition|expression|Requis|La condition à évaluer. Utilise les mêmes opérateurs que $if (==, !=, >, <, >=, <=).
param: error message|text|Requis|Message affiché à l'utilisateur si la condition échoue. Le script est interrompu après l'envoi de ce message.
</details>
