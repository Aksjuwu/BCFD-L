<dash>
name: $cooldown
desc: Empêche un utilisateur de ré-exécuter le script pendant une durée définie.
category: Contrôle d'accès

<block type="text" title="Comment fonctionne la commande ?">
text: $cooldown définit une restriction basée sur le temps, par utilisateur et par script. Si l'utilisateur tente d'exécuter le même script avant l'expiration du cooldown, le message d'erreur fourni s'affiche (avec le temps restant) et l'exécution est interrompue.
</block>

<block type="code" title="Syntaxe">
text: $cooldown[time; error message]
</block>

<block type="code" title="Exemple prêt à copier">
text: $cooldown[10s; Please wait {time} before using this again!]
</block>

<block type="callout" kind="note">
text: Le format du temps utilise : s (secondes), m (minutes), h (heures), d (jours). Utilisez {time} ou %time% dans le message d'erreur pour afficher le temps de cooldown restant.
</block>
</dash>

<details>
syntax: $cooldown[time; error message]
param: time|text|Requis|Durée avant que l'utilisateur puisse ré-exécuter le script. Format : nombre + unité (s/m/h/d), ex. 10s, 5m, 1h, 1d
param: error message|text|Requis|Message envoyé à l'utilisateur lorsque le cooldown est actif. Utilisez {time} ou %time% pour afficher le temps restant.
</details>
