<dash>
name: $log
desc: Prend un instantané de tous les événements du script et les envoie dans un canal spécifié.
category: Utilitaires

<block type="text" title="Comment fonctionne la commande ?">
text: $log capture tous les journaux d'événements générés pendant l'exécution du script en cours jusqu'à présent et les envoie dans le canal spécifié. Un code de nom optionnel peut être fourni pour étiqueter l'entrée du journal.
</block>

<block type="code" title="Syntaxe">
text: $log[channelID; name_code]
</block>

<block type="code" title="Exemple prêt à copier">
text: $log[123456789; myCommand]
</block>

<block type="callout" kind="note">
text: Le journal est envoyé sous forme de message dans le canal spécifié. Le paramètre name_code est optionnel et aide à étiqueter les différentes entrées du journal.
</block>
</dash>

<details>
syntax: $log[channelID; name_code]
param: channelID|snowflake|Requis|L'ID du canal vers lequel envoyer le journal
param: name_code|text|Optionnel|Une étiquette/nom pour cette entrée du journal
</details>
