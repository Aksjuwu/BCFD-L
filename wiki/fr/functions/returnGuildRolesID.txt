<dash>
name: $returnGuildRolesID
desc: Collecte les IDs des rôles d'un serveur, éventuellement filtrés par permission, et les stocke.
category: Commandes de retour

<block type="text" title="Comment fonctionne la commande ?">
text: $returnGuildRolesID collecte les IDs des rôles d'un serveur spécifié, en filtrant éventuellement selon une permission requise. Le résultat est stocké sous un nom de variable et peut être récupéré plus tard avec $return[variableName]. Si aucun filtre de permission n'est spécifié, tous les rôles (sauf @everyone) sont collectés.
</block>

<block type="code" title="Syntaxe">
text: $returnGuildRolesID[GuildID; permission; var; separator]
</block>

<block type="code" title="Exemple prêt à copier">
text: $returnGuildRolesID[$guildID; all; roleIDs; ,]
$sendMessage[Roles: $return[roleIDs]]
</block>

<block type="callout" kind="note">
text: Pour le paramètre permission : laissez vide ou utilisez "all" pour obtenir tous les rôles. Vous pouvez également spécifier une permission nommée (ex. : kick_members, manage_messages) ou un entier brut de permission. Seuls les rôles possédant la permission spécifiée (ou une supérieure) seront inclus.
</block>

<block type="callout" kind="warning">
text: Le bot doit être membre du serveur cible. Le rôle @everyone est toujours exclu des résultats.
</block>
</dash>

<details>
syntax: $returnGuildRolesID[GuildID; permission; var; separator]
param: GuildID|snowflake|Requis|L'ID du serveur dont il faut collecter les rôles
param: permission|text|Requis|Filtre de permission : laissez vide ou utilisez "all" pour tous les rôles, une permission nommée (ex. : kick_members) ou un entier brut de permission
param: var|text|Requis|Le nom de la variable dans laquelle stocker le résultat (à utiliser avec $return[])
param: separator|text|Requis|Le séparateur entre les IDs multiples (ex. : , ou ;). Vous pouvez utiliser des séparateurs nommés : dot, com, apo, sem, colon
</details>
