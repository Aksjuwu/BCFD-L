<dash>
name: $elif
desc: Fournit une condition alternative dans un bloc $if lorsque les conditions précédentes étaient fausses.
category: Contrôle de flux

<block type="text" title="Comment fonctionne la commande ?">
text: $elif est utilisé dans un bloc $if pour ajouter des conditions supplémentaires. Lorsque la condition $if (ou $elif) précédente est fausse, la condition $elif suivante est vérifiée. Si elle est vraie, son bloc de code est exécuté.
</block>

<block type="code" title="Syntaxe">
text: $elif[condition]
</block>

<block type="code" title="Exemple prêt à copier">
text: $if[$message == hello]
  Hi there!
$elif[$message == bye]
  Goodbye!
$endif
</block>

<block type="callout" kind="note">
text: $elif doit être placé entre un $if et un $endif. Plusieurs blocs $elif peuvent être enchaînés. Seul le bloc de code de la première condition correspondante est exécuté.
</block>
</dash>

<details>
syntax: $elif[condition]
param: condition|expression|Requis|La condition à évaluer (par exemple, $message == hello, $authorID == 123). Utilise les mêmes opérateurs que $if.
</details>
