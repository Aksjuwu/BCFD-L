<dash>
name: $else
desc: Fournit un bloc de code alternatif lorsque la condition $if précédente est fausse.
category: Contrôle de flux

<block type="text" title="Comment fonctionne la commande ?">
text: Lorsqu'il est utilisé dans un bloc $if, $else définit un chemin de code de secours. Si la condition $if est évaluée comme fausse, le code après $else (et avant $endif) est exécuté à la place.
</block>

<block type="code" title="Syntaxe">
text: $else
</block>

<block type="code" title="Exemple prêt à copier">
text: $if[$authorID == 123456789]
  Hello Admin!
$else
  You are not an admin.
$endif
</block>

<block type="callout" kind="note">
text: $else doit être placé entre un $if et un $endif. Utiliser $else en dehors d'un bloc $if entraînera une erreur.
</block>
</dash>
