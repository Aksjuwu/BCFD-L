<dash>
name: $return
desc: Récupère une valeur stockée par une commande $returnXxx et l'envoie dans le canal.
category: Variables

<block type="text" title="Comment fonctionne la commande ?">
text: $return prend un nom de variable et recherche sa valeur dans le stockage des variables de retour. Ce stockage est rempli par des commandes comme $returnGuildUsersID, $returnGuildChannelsID, etc. Utilisé seul, la valeur récupérée est envoyée dans le canal ; utilisé en ligne dans les arguments d'une autre commande, la valeur est substituée directement dans le texte.
</block>

<block type="code" title="Syntaxe">
text: $return[var]
</block>

<block type="code" title="Exemple prêt à copier">
text: $returnGuildUsersID[$guildID; cache; userIDs; ,]
$sendMessage[User IDs: $return[userIDs]]
</block>

<block type="callout" kind="note">
text: Si le nom de variable n'existe pas dans le stockage de retour, une erreur est renvoyée. Assurez-vous d'appeler la commande $returnXxx appropriée avant d'utiliser $return.
</block>
</dash>

<details>
syntax: $return[var]
param: variable|text|Requis|Le nom de la variable de retour à récupérer (ex. : userIDs, channelIDs, roleIDs)
</details>
