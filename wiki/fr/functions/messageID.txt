<dash>
name: $messageID
desc: Renvoie l'ID de message Discord du message qui a déclenché la commande.
category: Info

<block type="text" title="Comment fonctionne la commande ?">
text: Lorsque $messageID est appelé, le bot récupère l'ID de message Discord unique du message déclencheur et l'envoie directement sous forme de chaîne numérique brute.
</block>

<block type="code" title="Syntaxe">
text: $messageID
</block>

<block type="code" title="Exemple prêt à copier">
text: Your message ID is $messageID
</block>

<block type="callout" kind="note">
text: La valeur renvoyée est un ID snowflake (p. ex. 123456789012345678), qui identifie de manière unique le message ayant déclenché le script.
</block>
</dash>
