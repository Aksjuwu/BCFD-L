<dash>
name: $membersCount
desc: Renvoie le nombre de membres d'un serveur.
category: Info

<block type="text" title="Comment fonctionne la commande ?">
text: Lorsque $membersCount est appelé sans arguments, le bot compte tous les membres humains (non-bots) du serveur actuel et envoie le nombre. Lorsqu'il est appelé avec un ID de serveur et un indicateur oui/non, il compte les membres de ce serveur spécifique et inclut éventuellement les bots.
</block>

<block type="code" title="Syntaxe">
text: $membersCount
text: $membersCount[guildID; includeBots]
</block>

<block type="code" title="Exemple prêt à copier">
text: We have $membersCount members!
</block>

<block type="callout" kind="note">
text: Par défaut, les bots sont exclus du décompte. Pour inclure les bots, utilisez $membersCount[guildID; yes]. Sans arguments, cette commande ne fonctionne que dans un serveur. Lorsque vous fournissez un ID de serveur, le bot doit être membre de ce serveur.
</block>
</dash>

<details>
syntax: $membersCount[(guildID; includeBots)]
param: guildID|snowflake|Optionnel|L'ID d'un autre serveur dans lequel compter les membres. Si omis, utilise le serveur actuel.
param: includeBots|yes/no|Optionnel|Définir sur « yes » pour inclure les comptes de bots dans le décompte. Si omis, seuls les membres humains sont comptés.
</details>
