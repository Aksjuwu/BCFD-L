<dash>
name: $onBotMessage
desc: Événement déclenché à chaque message envoyé par un bot (y compris les autres bots).
category: Événement

<block type="text" title="Comment fonctionne l'événement ?">
text: $onBotMessage est un préfixe d'événement qui déclenche un FDScript à chaque fois qu'un bot envoie un message. Par défaut, le script ignore les messages envoyés par le bot lui-même et ne réagit qu'aux autres bots. Définissez l'argument sur yes pour exécuter aussi le script sur les messages du bot lui-même, ou sur no pour ignorer ses propres messages (c'est également la valeur par défaut lorsque l'argument est vide).
</block>

<block type="code" title="Syntaxe">
text: #PREFIX:$onBotMessage[yes/no]
</block>

<block type="code" title="Exemple prêt à copier">
text: #PREFIX:$onBotMessage[no]
$sendMessage[Another bot said: $message]
</block>

<block type="callout" kind="note">
text: Utilisez yes pour suivre les messages du bot lui-même, ou no pour ne réagir qu'aux autres bots. L'exemple ci-dessus utilise $message pour lire le contenu du message du bot.
</block>

<block type="callout" kind="important">
text: Cet événement s'exécute dans le dossier bot_events, pas bot_commands. Créez votre fichier .fds à cet endroit.
</block>
</dash>

<details>
syntax: #PREFIX:$onBotMessage[(yes/no)]
param: yes/no|text|Optionnel|yes pour exécuter aussi le script sur les messages du bot lui-même, no (par défaut) pour ne réagir qu'aux autres bots
</details>
