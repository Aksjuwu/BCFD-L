<dash>
name: $slowmode
desc: Définit le délai de mode lent pour un canal spécifié.
category: Modération

<block type="text" title="Comment fonctionne la commande ?">
text: $slowmode prend un ID de canal et une durée, puis définit le délai de mode lent pour ce canal. Le mode lent limite la fréquence à laquelle les utilisateurs peuvent envoyer des messages.
</block>

<block type="code" title="Syntaxe">
text: $slowmode[channelID; time]
</block>

<block type="code" title="Exemple prêt à copier">
text: $slowmode[$channelID; 10s]
</block>

<block type="callout" kind="note">
text: Le format de temps utilise : s (secondes), m (minutes), h (heures). Le mode lent maximal est de 6 heures (21600 secondes). Utilisez 0s pour désactiver le mode lent.
</block>

<block type="callout" kind="warning">
text: Le bot doit avoir la permission "Gérer les canaux" dans le canal cible.
</block>
</dash>

<details>
syntax: $slowmode[channelID; time]
param: channelID|snowflake|Requis|L'ID du canal pour lequel définir le mode lent
param: durée|text|Requis|Durée du mode lent. Format : nombre + unité (s/m/h), ex. : 10s, 5m, 0s pour désactiver
</details>
