<dash>
name: $onJoined
desc: Événement déclenché lorsqu'un membre rejoint le serveur.
category: Événement

<block type="text" title="Comment fonctionne l'événement ?">
text: $onJoined est un préfixe d'événement qui déclenche un FDScript à chaque fois qu'un nouveau membre rejoint le serveur. Le script reçoit les informations du membre qui rejoint. Vous pouvez éventuellement spécifier un ID de canal dans la première ligne pour diriger la sortie vers un canal spécifique.
</block>

<block type="code" title="Syntaxe">
text: #PREFIX:$onJoined
</block>

<block type="code" title="Exemple prêt à copier">
text: #PREFIX:$onJoined
 sendMessage[Welcome $mention to the server!]
</block>

<block type="callout" kind="note">
text: Placez ceci dans la première ligne de votre fichier FDScript. Le script s'exécutera automatiquement à chaque arrivée de membre. Utilisez $mention pour mentionner le nouveau membre.
</block>

<block type="callout" kind="important">
text: Cet événement s'exécute dans le dossier bot_events, pas bot_commands. Créez votre fichier .fds à cet endroit.
</block>
</dash>
