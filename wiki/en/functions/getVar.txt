<dash>
name: $getVar
desc: Retrieves the value of a persistent variable by name.
category: Variables

<block type="text" title="How does the command work?">
text: $getVar looks up a stored variable by its name. With one argument, it retrieves a global variable. With two arguments (name and user ID), it retrieves a user-specific variable. The stored value is sent to the channel.
</block>

<block type="code" title="Syntax">
text: $getVar[name]
</block>

<block type="code" title="Ready-to-copy Example">
text: $getVar[mySetting]
</block>

<block type="callout" kind="note">
text: Variables are persistent — they survive bot restarts. Use $setVar to store values. If the variable doesn't exist, an empty string is returned.
</block>
</dash>

<details>
syntax: $getVar[name; (userID)]
param: name|text|Required|The name of the variable to retrieve
param: userID|snowflake|Optional|If provided, retrieves the user-specific value for this variable instead of the global value
</details>
