<dash>
name: $log
desc: Takes a snapshot of all script events and sends them to a specified channel.
category: Utilities

<block type="text" title="How does the command work?">
text: $log captures all event logs generated during the current script execution so far and sends them to the specified channel. An optional name code can be provided to label the log entry.
</block>

<block type="code" title="Syntax">
text: $log[channelID; name_code]
</block>

<block type="code" title="Ready-to-copy Example">
text: $log[123456789; myCommand]
</block>

<block type="callout" kind="note">
text: The log is sent as a message to the specified channel. The name_code parameter is optional and helps label different log entries.
</block>
</dash>

<details>
syntax: $log[channelID; name_code]
param: channelID|snowflake|Required|The ID of the channel to send the log to
param: name_code|text|Optional|A label/name for this log entry
</details>
