<dash>
name: $onLeave
desc: Event triggered when a member leaves the server.
category: Event

<block type="text" title="How does the event work?">
text: $onLeave is an event prefix that triggers an FDScript whenever a member leaves or is removed from the server. The script receives the departing member's information. You can optionally specify a channel ID in the first line to direct the output to a specific channel.
</block>

<block type="code" title="Syntax">
text: #PREFIX:$onLeave
</block>

<block type="code" title="Ready-to-copy Example">
text: #PREFIX:$onLeave
 sendMessage[Goodbye $authorName!]
</block>

<block type="callout" kind="note">
text: Place this in the first line of your FDScript file. The script will run automatically when any member leaves.
</block>

<block type="callout" kind="important">
text: This event runs in the bot_events folder, not bot_commands. Create your .fds file there.
</block>
</dash>
