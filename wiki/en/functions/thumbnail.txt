<dash>
name: $thumbnail
desc: Sets the thumbnail image of an embed using a URL.
category: Embed Builder

<block type="text" title="How does the command work?">
text: $thumbnail places a large image in the top-right corner of the target embed. Any argument containing a valid web address works - the command extracts the first URL found. The optional last numeric argument selects which embed to edit.
</block>

<block type="code" title="Syntax">
text: $thumbnail[url;(index)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $title[Server stats]
text: $thumbnail[https://example.com/chart.png]
</block>

<block type="callout" kind="note">
text: The URL must start with http:// or https://. Trailing punctuation after the URL is trimmed automatically. An error is raised if no valid URL is found.
</block>
</dash>

<details>
syntax: $thumbnail[url;(index)]
param: url|text|Required|Text containing the image URL (http:// or https://)
param: index|number|Optional|Embed number to edit when several embeds are being built (default 1)
</details>
