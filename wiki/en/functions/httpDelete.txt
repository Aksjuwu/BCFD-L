<dash>
name: $httpDelete
desc: Sends an HTTP DELETE request to a URL with an optional body.
category: HTTP

<block type="text" title="How does the command work?">
text: $httpDelete sends a DELETE request with a 10 second timeout. The body is sent as JSON when it is valid JSON, otherwise as raw text. The response is stored in $httpResult and the status code in $httpStatus. Headers added with $httpAddHeader are sent and then cleared.
</block>

<block type="code" title="Syntax">
text: $httpDelete[URL; (Body)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $httpDelete[https://api.example.com/users/1]
$httpStatus
</block>

<block type="callout" kind="note">
text: If the body is valid JSON it is sent as JSON, otherwise it is sent as raw data. On failure the status is set to 500 and $httpResult contains the error message.
</block>
</dash>

<details>
syntax: $httpDelete[URL; (Body)]
param: URL|text|Required|The URL to send the DELETE request to
param: Body|text|Optional|The request body (JSON or raw text)
</details>
