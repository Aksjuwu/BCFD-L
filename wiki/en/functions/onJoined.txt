<dash>
name: $onJoined
desc: Event triggered when a member joins the server.
category: Event

<block type="text" title="How does the event work?">
text: $onJoined is an event prefix that triggers an FDScript whenever a new member joins the server. The script receives the joining member's information. You can optionally specify a channel ID in the first line to direct the output to a specific channel.
</block>

<block type="code" title="Syntax">
text: #PREFIX:$onJoined
</block>

<block type="code" title="Ready-to-copy Example">
text: #PREFIX:$onJoined
 sendMessage[Welcome $mention to the server!]
</block>

<block type="callout" kind="note">
text: Place this in the first line of your FDScript file. The script will run automatically when any member joins. Use $mention to tag the new member.
</block>

<block type="callout" kind="important">
text: This event runs in the bot_events folder, not bot_commands. Create your .fds file there.
</block>
</dash>
