<dash>
name: $httpPut
desc: Sends an HTTP PUT request to a URL with an optional body.
category: HTTP

<block type="text" title="How does the command work?">
text: $httpPut sends a PUT request with a 10 second timeout. The body is sent as JSON when it is valid JSON, otherwise as raw text. The response is stored in $httpResult and the status code in $httpStatus. Headers added with $httpAddHeader are sent and then cleared.
</block>

<block type="code" title="Syntax">
text: $httpPut[URL; (Body)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $httpAddHeader[Content-Type; application/json]
$httpPut[https://api.example.com/users/1; {"name": "FDScript"}]
$httpStatus
</block>

<block type="callout" kind="note">
text: If the body is valid JSON it is sent as JSON, otherwise it is sent as raw data. On failure the status is set to 500 and $httpResult contains the error message.
</block>
</dash>

<details>
syntax: $httpPut[URL; (Body)]
param: URL|text|Required|The URL to send the PUT request to
param: Body|text|Optional|The request body (JSON or raw text)
</details>
