<dash>
name: $deletecommand
desc: Deletes the message that triggered the command.
category: Moderation

<block type="text" title="How does the command work?">
text: When $deletecommand is called, the bot attempts to delete the user's message that triggered the script execution. This is commonly used to keep channels clean by removing the original command invocation.
</block>

<block type="code" title="Syntax">
text: $deletecommand
</block>

<block type="code" title="Ready-to-copy Example">
text: $deletecommand
$sendMessage[Command received!]
</block>

<block type="callout" kind="warning">
text: The bot must have the "Manage Messages" permission in the channel to delete user messages. If the permission is missing, the command will fail silently with an error log.
</block>
</dash>
