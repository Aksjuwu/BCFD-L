<dash>
name: $addUserReactions
desc: Adds one or more emoji reactions to the user's original message that triggered the command.
category: Components

<block type="text" title="How does the command work?">
text: $addUserReactions takes one or more emoji arguments, resolves any variables/placeholders inside them, and adds each resulting emoji as a reaction to the user's triggering message. It reacts in order with a short delay between each to avoid rate limits.
</block>

<block type="code" title="Syntax">
text: $addUserReactions[emoji1; emoji2; emoji3; ...]
</block>

<block type="code" title="Ready-to-copy Example">
text: $addUserReactions[👍; ❤️]
</block>

<block type="callout" kind="note">
text: Rate limits are handled automatically — if Discord returns a 429, the command waits and retries that specific emoji once before continuing.
</block>

<block type="callout" kind="warning">
text: If no valid emojis are found in the arguments, the command silently does nothing. The bot must have "Add Reactions" permission in the channel.
</block>
</dash>

<details>
syntax: $addUserReactions[emoji1; emoji2; emoji3; ...]
param: emoji|text|Required|One or more emoji values to react with. All arguments are resolved (variables/placeholders supported) and merged, then every emoji found is added as a reaction to the user's message, in order.
</details>
