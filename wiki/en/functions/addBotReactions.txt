<dash>
name: $addBotReactions
desc: Adds one or more emoji reactions to the last message the bot sent during this script's execution.
category: Components

<block type="text" title="How does the command work?">
text: $addBotReactions takes one or more emoji arguments, resolves any variables/placeholders inside them, and adds each resulting emoji as a reaction to the last message sent by the bot in the current script run. It reacts to arguments in order, with a short delay between each reaction to avoid rate limits.
</block>

<block type="code" title="Syntax">
text: $addBotReactions[emoji1; emoji2; emoji3; ...]
</block>

<block type="code" title="Ready-to-copy Example">
text: $addBotReactions[✅; ❌; 🎉]
</block>

<block type="list" title="Requirements">
item: A bot message must have already been sent earlier in the same script execution.
item: At least one valid emoji must be extracted from the given arguments.
item: The bot must have the "Add Reactions" permission in the channel.
</block>

<block type="callout" kind="note">
text: Rate limits are handled automatically — if Discord returns a 429 (Too Many Requests), the command waits and retries that specific emoji once before moving on.
</block>

<block type="callout" kind="warning">
text: There is a maximum of 20 emojis allowed per call. Exceeding this limit will cause the command to fail with an error instead of adding any reactions.
</block>

<block type="callout" kind="important">
text: If no bot message was sent yet, or none of the given arguments resolve to valid emojis, the command fails immediately and no reactions are added.
</block>
</dash>

<details>
syntax: $addBotReactions[emoji1; emoji2; emoji3; ...]
param: emoji|text|Required|One or more emoji values to react with. All arguments are resolved (variables/placeholders supported) and merged, then every emoji found inside the resulting text is added as a reaction, in order.
</details>
