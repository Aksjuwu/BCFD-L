<dash>
name: $cooldown
desc: Prevents a user from re-running the script for a specified duration.
category: Access Control

<block type="text" title="How does the command work?">
text: $cooldown sets a time-based restriction per user per script. If the user tries to run the same script again before the cooldown expires, the provided error message is displayed (with remaining time) and execution is aborted.
</block>

<block type="code" title="Syntax">
text: $cooldown[time; error message]
</block>

<block type="code" title="Ready-to-copy Example">
text: $cooldown[10s; Please wait {time} before using this again!]
</block>

<block type="callout" kind="note">
text: The time format uses: s (seconds), m (minutes), h (hours), d (days). Use {time} or %time% in the error message to show the remaining cooldown time.
</block>
</dash>

<details>
syntax: $cooldown[time; error message]
param: time|text|Required|Duration before the user can run the script again. Format: number + unit (s/m/h/d), e.g., 10s, 5m, 1h, 1d
param: error message|text|Required|Message sent to the user when cooldown is active. Use {time} or %time% to display remaining time.
</details>
