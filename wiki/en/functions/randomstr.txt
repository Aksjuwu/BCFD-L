<dash>
name: $randomstr
desc: Returns a randomly selected string from the provided arguments.
category: Randomness

<block type="text" title="How does the command work?">
text: $randomstr takes one or more string arguments and randomly picks one, then sends it to the channel. This is useful for random responses, quotes, or messages.
</block>

<block type="code" title="Syntax">
text: $randomstr[string1; string2; string3; ...]
</block>

<block type="code" title="Ready-to-copy Example">
text: $randomstr[Hello!; Hi there!; Hey!; What's up?]
</block>

<block type="callout" kind="note">
text: Each argument is a possible output. One is chosen at random with equal probability. At least one string must be provided.
</block>
</dash>

<details>
syntax: $randomstr[string1; string2; string3; ...]
param: string|text|Required|One or more strings to choose from. One is randomly selected and sent.
</details>
