<dash>
name: $channelExists
desc: Checks if a channel exists in the server.
category: Channel

<block type="text" title="How does the command work?">
text: $channelExists takes a channel mention or ID and checks whether the bot can find that channel in the server. Returns "true" if the channel exists, "false" otherwise. If no argument is provided, returns "true" by default.
</block>

<block type="code" title="Syntax">
text: $channelExists[channel mention/ID]
</block>

<block type="code" title="Ready-to-copy Example">
text: $channelExists[<#123456789012345678>]
</block>

<block type="callout" kind="note">
text: This command can be used inline to check channel existence before performing other actions on that channel.
</block>
</dash>

<details>
syntax: $channelExists[channel mention/ID]
param: channel|text|Optional|The channel mention or numeric ID to check. If empty, returns "true".
</details>
