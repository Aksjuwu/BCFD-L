<dash>
name: $and
desc: Evaluates multiple conditions and returns true only if ALL conditions are true.
category: Flow Control

<block type="text" title="How does the command work?">
text: $and takes multiple condition arguments and evaluates each one. It returns "true" if every single condition is true, and "false" if any condition is false. This is useful for building compound conditional checks.
</block>

<block type="code" title="Syntax">
text: $and[condition1; condition2; condition3; ...]
</block>

<block type="code" title="Ready-to-copy Example">
text: $and[$authorID == 123; $guildName == MyServer]
</block>

<block type="callout" kind="note">
text: Each condition uses the same comparison operators as $if (==, !=, >, <, >=, <=). Returns the string "true" or "false".
</block>
</dash>

<details>
syntax: $and[condition1; condition2; condition3; ...]
param: condition|expression|Required|One or more conditions to evaluate. Each can use operators like ==, !=, >, <, >=, <=. All must be true for the result to be "true".
</details>
