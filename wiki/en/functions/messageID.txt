<dash>
name: $messageID
desc: Returns the Discord message ID of the message that triggered the command.
category: Info

<block type="text" title="How does the command work?">
text: When $messageID is called, the bot retrieves the unique Discord message ID of the triggering message and sends it directly as a raw numeric string.
</block>

<block type="code" title="Syntax">
text: $messageID
</block>

<block type="code" title="Ready-to-copy Example">
text: Your message ID is $messageID
</block>

<block type="callout" kind="note">
text: The returned value is a snowflake ID (e.g., 123456789012345678), which uniquely identifies the message that triggered the script.
</block>
</dash>
