<dash>
name: $createChannel
desc: Creates a new channel in the server.
category: Channel Management

<block type="text" title="How does the command work?">
text: $createChannel creates a new channel in the server with the specified name and type. Supports text, voice, category, forum, and stage channel types. An optional category ID can be provided to place the channel under a specific category. The bot must have "Manage Channels" permission.
</block>

<block type="code" title="Syntax">
text: $createChannel[name; type; (category ID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $createChannel[my-channel; text]
</block>

<block type="callout" kind="warning">
text: The bot must have "Manage Channels" permission. Supported types: text, voice, category, forum, stage.
</block>

<block type="callout" kind="note">
text: The category ID is optional. If provided, the new channel will be created under that category.
</block>
</dash>

<details>
syntax: $createChannel[name; type; (category ID)]
param: name|text|Required|The name of the new channel.
param: type|text|Required|The channel type: text, voice, category, forum, or stage.
param: categoryID|text|Optional|The ID of the category to place the channel under.
</details>
