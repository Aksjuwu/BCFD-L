<dash>
name: $onlyIf
desc: Evaluates a condition and aborts the script if the condition is false.
category: Access Control

<block type="text" title="How does the command work?">
text: $onlyIf evaluates a condition. If the condition is true, the script continues normally. If false, the provided error message is displayed and the script is immediately aborted.
</block>

<block type="code" title="Syntax">
text: $onlyIf[condition; error message]
</block>

<block type="code" title="Ready-to-copy Example">
text: $onlyIf[$authorID == 123456789; You are not authorized!]
</block>

<block type="callout" kind="note">
text: This is stricter than $if — it doesn't just skip code, it completely stops the entire script. Use this for access control checks that must pass for the script to run.
</block>
</dash>

<details>
syntax: $onlyIf[condition; error message]
param: condition|expression|Required|The condition to evaluate. Uses the same operators as $if (==, !=, >, <, >=, <=).
param: error message|text|Required|Message displayed to the user if the condition fails. The script is aborted after sending this.
</details>
