<dash>
name: $dm
desc: Sets the destination for subsequent messages to be sent as a direct message (DM) to a user.
category: Messaging

<block type="text" title="How does the command work?">
text: When $dm is called without arguments, it sets the message destination to the command author's DMs. When called with a user ID or mention, it sets the destination to that user's DMs. All subsequent $sendMessage calls will be sent to the DM target.
</block>

<block type="code" title="Syntax">
text: $dm
</block>

<block type="code" title="Ready-to-copy Example">
text: $dm
$sendMessage[Check your DMs!]
</block>

<block type="callout" kind="note">
text: The bot and the target user must share a server for DMs to work. If the user has DMs disabled, the message will fail to send. Using $dm without brackets targets the command author.
</block>
</dash>
