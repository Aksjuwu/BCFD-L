<dash>
name: $sub
desc: Subtracts numbers sequentially from the first value and returns the result.
category: Math & Numbers

<block type="text" title="How does the command work?">
text: $sub takes two or more numeric arguments. It starts with the first value and subtracts each subsequent value from it. Works both as a standalone command and inline.
</block>

<block type="code" title="Syntax">
text: $sub[a; b; ...]
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[Result is $sub[10; 3]]
</block>

<block type="callout" kind="note">
text: $sub[10; 3; 2] evaluates to 10 - 3 - 2 = 5. If a non-numeric value is provided, an error is returned.
</block>
</dash>

<details>
syntax: $sub[a; b; ...]
param: a|number|Required|The starting value (minuend)
param: b|number|Required|The value to subtract (additional values are also subtracted sequentially)
</details>
