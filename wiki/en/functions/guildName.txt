<dash>
name: $guildName
desc: Returns the name of the server (guild) where the command was used.
category: Info

<block type="text" title="How does the command work?">
text: When $guildName is called, the bot retrieves the name of the server where the command was executed and sends it directly to the channel as a plain text string. If used in a DM, it returns "DM".
</block>

<block type="code" title="Syntax">
text: $guildName
</block>

<block type="code" title="Ready-to-copy Example">
text: Welcome to $guildName!
</block>

<block type="callout" kind="note">
text: When used outside a server (in DMs), the command returns the string "DM" instead of a server name.
</block>
</dash>
