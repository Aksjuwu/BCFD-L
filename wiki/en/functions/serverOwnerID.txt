<dash>
name: $serverOwnerID
desc: Returns the Discord user ID of the server owner.
category: Info

<block type="text" title="How does the command work?">
text: When $serverOwnerID is called, the bot retrieves the unique Discord user ID of the server owner and sends it directly as a raw numeric string.
</block>

<block type="code" title="Syntax">
text: $serverOwnerID
</block>

<block type="code" title="Ready-to-copy Example">
text: Server owner ID: $serverOwnerID
</block>

<block type="callout" kind="note">
text: This command only works inside a server (not in DMs). The returned value is the snowflake user ID of the account that owns the server.
</block>
</dash>
