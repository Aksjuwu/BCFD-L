<dash>
name: $returnGetReactions
desc: Fetches users who reacted with a specific emoji on a message and stores the result.
category: Return Commands

<block type="text" title="How does the command work?">
text: $returnGetReactions fetches a specific message, finds all users (or counts) who reacted with a given emoji, and stores the result. You can retrieve user IDs or the total reaction count.
</block>

<block type="code" title="Syntax">
text: $returnGetReactions[channelID; messageID; type; var; separator; emoji]
</block>

<block type="code" title="Ready-to-copy Example">
text: $returnGetReactions[$channelID; 123456789; usersID; reactors; ,; 👍]
</block>

<block type="callout" kind="note">
text: The type parameter accepts "usersID" (to get user IDs) or "tr" (to get total reaction count). The separator defines how multiple values are joined.
</block>
</dash>

<details>
syntax: $returnGetReactions[channelID; messageID; type; var; separator; emoji]
param: channelID|snowflake|Required|The ID of the channel containing the message
param: messageID|snowflake|Required|The ID of the message to check reactions on
param: type|text|Required|usersID to get user IDs, or tr to get total reaction count
param: var|text|Required|The variable name to store the result in
param: separator|text|Required|The separator to use between multiple values (e.g., , or ; )
param: emoji|text|Required|The emoji to look for reactions with
</details>
