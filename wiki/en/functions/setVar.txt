<dash>
name: $setVar
desc: Stores a value in a persistent variable.
category: Variables

<block type="text" title="How does the command work?">
text: $setVar stores a value under a given variable name. With two arguments, it stores a global variable. With three arguments (name, value, user ID), it stores a user-specific variable. Values persist across bot restarts.
</block>

<block type="code" title="Syntax">
text: $setVar[name; value]
</block>

<block type="code" title="Ready-to-copy Example">
text: $setVar[greeting; Hello World!]
</block>

<block type="callout" kind="note">
text: Variables are stored on disk and survive bot restarts. Use $getVar to retrieve stored values. $setVar cannot be used inline (as a placeholder).
</block>
</dash>

<details>
syntax: $setVar[name; value; (userID)]
param: name|text|Required|The variable name to store the value under
param: value|text|Required|The value to store
param: userID|snowflake|Optional|If provided, stores the value as user-specific instead of global
</details>
