<dash>
name: $elif
desc: Provides an alternative condition within an $if block when the previous conditions were false.
category: Flow Control

<block type="text" title="How does the command work?">
text: $elif is used inside an $if block to add additional conditions. When the preceding $if (or $elif) condition is false, the next $elif condition is checked. If it is true, its code block is executed.
</block>

<block type="code" title="Syntax">
text: $elif[condition]
</block>

<block type="code" title="Ready-to-copy Example">
text: $if[$message == hello]
  Hi there!
$elif[$message == bye]
  Goodbye!
$endif
</block>

<block type="callout" kind="note">
text: $elif must be placed between an $if and an $endif. Multiple $elif blocks can be chained. Only the first matching condition's code block is executed.
</block>
</dash>

<details>
syntax: $elif[condition]
param: condition|expression|Required|The condition to evaluate (e.g., $message == hello, $authorID == 123). Uses the same operators as $if.
</details>
