<dash>
name: $roleAssign
desc: Adds or removes one or more roles from a server member.
category: Moderation

<block type="text" title="How does the command work?">
text: $roleAssign takes a user as the first argument, followed by one or more role operations. Each role operation starts with + to add the role or - to remove it, followed by the role ID or mention. Multiple roles can be assigned or removed in a single call.
</block>

<block type="code" title="Syntax">
text: $roleAssign[user; +role1; -role2; ...]
</block>

<block type="code" title="Ready-to-copy Example">
text: $roleAssign[$authorID; +&123456789; -&987654321]
</block>

<block type="options" title="Role prefixes">
option: +|Adds the role to the user (e.g., +&123456789 or +@RoleName)
option: -|Removes the role from the user (e.g., -&123456789 or -@RoleName)
</block>

<block type="callout" kind="note">
text: You can assign and remove multiple roles in a single call. The user is always the first argument. The bot must have "Manage Roles" permission and its highest role must be above the roles being assigned.
</block>

<block type="callout" kind="warning">
text: The target user must be a member of the server. If a role ID is invalid, that role operation is skipped. If the bot lacks permissions or the role hierarchy is an issue, an error is returned.
</block>
</dash>

<details>
syntax: $roleAssign[user; +role1; -role2; ...]
param: user|text|Required|The user ID or @mention of the member to modify roles for
param: +role1|text|Required|A role to ADD: prefix with + followed by role ID or @mention (e.g., +&123456789)
param: -role2|text|Optional|A role to REMOVE: prefix with - followed by role ID or @mention. You can include multiple +/- role operations.
</details>
