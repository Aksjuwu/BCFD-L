<dash>
name: $addButton
desc: Adds a button (Button) to the message being built, or to a previously sent message via its ID.
category: Components

<block type="text" title="How does the command work?">
text: $addButton adds one button per call. You can control the button type (link or interactive), style, state (enabled/disabled), and position (same row or new row).
</block>

<block type="code" title="Syntax">
text: $addButton[newLine; ID/URL; label; style; (disabled; emoji; messageID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $addButton[no; btn_confirm; Confirm; success]
</block>

<block type="options" title="Button styles (style)">
option: primary|Blue button (default color)
option: secondary|Grey button
option: success|Green button
option: danger|Red button
option: link|External link button (no custom_id, does not trigger a bot interaction)
</block>

<block type="callout" kind="note">
text: When style = link, the second argument (ID/URL) must be a full URL starting with http:// or https://.
</block>

<block type="callout" kind="warning">
text: Maximum 25 buttons per message (5 rows × 5 buttons per row). When the current row is full, the button automatically moves to a new row.
</block>
</dash>

<details>
syntax: $addButton[newLine; ID/URL; label; style; (disabled; emoji; messageID)]
param: newLine|yes/no|Required|Does the button start on a new row? yes = new row, no = same row next to the last button
param: ID/URL|text|Required|Custom ID for the interactive button, or a full URL if style = link
param: label|text|Emptiable|The text displayed on the button
param: style|text|Required|primary / secondary / success / danger / link
param: disabled|yes/no|Optional|yes to disable the button (default: no)
param: emoji|text|Optional|An emoji to display inside the button
param: messageID|snowflake|Optional|ID of a previously sent bot message to add the button to instead of the current message
</details>
