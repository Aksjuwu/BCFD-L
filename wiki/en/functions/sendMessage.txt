<dash>
name: $sendMessage
desc: Sends a text message to the current channel.
category: Messaging

<block type="text" title="How does the command work?">
text: $sendMessage takes a text argument, resolves any variables/placeholders inside it, and sends the resulting message to the current channel. If a view with buttons is pending, it attaches them to the message.
</block>

<block type="code" title="Syntax">
text: $sendMessage[text]
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[Hello, $authorName!]
</block>

<block type="callout" kind="note">
text: This is the primary way to send messages in FDScript. Variables and placeholders inside the text are automatically resolved before sending.
</block>
</dash>

<details>
syntax: $sendMessage[text]
param: text|text|Required|The message text to send. Supports variables, placeholders, and Discord markdown.
</details>
