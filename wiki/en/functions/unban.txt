<dash>
name: $unban
desc: Unbans a previously banned user from the server.
category: Moderation

<block type="text" title="How does the command work?">
text: $unban takes a user ID, looks up the user in the server's ban list, and removes the ban. The user must have been previously banned to use this command.
</block>

<block type="code" title="Syntax">
text: $unban[userID]
</block>

<block type="code" title="Ready-to-copy Example">
text: $unban[123456789]
</block>

<block type="callout" kind="warning">
text: The bot must have "Ban Members" permission. The user ID must be a raw numeric ID (mentions and symbols are not supported). The user must currently be banned.
</block>
</dash>

<details>
syntax: $unban[userID]
param: userID|snowflake|Required|The numeric user ID of the banned user to unban
</details>
