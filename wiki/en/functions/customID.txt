<dash>
name: $customID
desc: Returns the custom_id of the button or component interaction that triggered the script.
category: Info

<block type="text" title="How does the command work?">
text: When a user clicks a button or interacts with a component, $customID returns the custom_id string assigned to that component. This is useful for identifying which button was pressed in an onInteraction event.
</block>

<block type="code" title="Syntax">
text: $customID
</block>

<block type="code" title="Ready-to-copy Example">
text: $if[$customID == btn_confirm]
  You confirmed!
$elif[$customID == btn_cancel]
  You cancelled!
$endif
</block>

<block type="callout" kind="note">
text: This variable is only meaningful inside interaction-triggered scripts (e.g., onInteraction). When used in a regular message context, it returns an empty string.
</block>
</dash>
