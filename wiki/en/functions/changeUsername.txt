<dash>
name: $changeUsername
desc: Changes the nickname of a server member.
category: Moderation

<block type="text" title="How does the command work?">
text: $changeUsername takes a user ID/mention and a new name. The bot looks up the member in the server and changes their nickname to the provided name using the Discord API.
</block>

<block type="code" title="Syntax">
text: $changeUsername[user ID/mention; new name]
</block>

<block type="code" title="Ready-to-copy Example">
text: $changeUsername[123456789; NewNickname]
</block>

<block type="callout" kind="warning">
text: The bot must have "Manage Nicknames" permission and its highest role must be above the target's highest role. The bot cannot change its own nickname or the server owner's nickname.
</block>
</dash>

<details>
syntax: $changeUsername[user ID/mention; new name]
param: user ID/mention|text|Required|The target member's Discord user ID or @mention
param: new name|text|Required|The new nickname to assign. Leave empty to reset to default.
</details>
