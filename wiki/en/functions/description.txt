<dash>
name: $description
desc: Sets the description text of the embed being built.
category: Embed Builder

<block type="text" title="How does the command work?">
text: $description takes a text argument and sets it as the main body/description of the current embed being constructed. This is the primary content area of the embed.
</block>

<block type="code" title="Syntax">
text: $description[text]
</block>

<block type="code" title="Ready-to-copy Example">
text: $description[This is the embed body text]
</block>

<block type="callout" kind="note">
text: The description supports Discord markdown formatting (bold, italic, code blocks, etc.). It appears below the title in the embed.
</block>
</dash>

<details>
syntax: $description[text]
param: text|text|Required|The description text for the embed. Supports Discord markdown formatting.
</details>
