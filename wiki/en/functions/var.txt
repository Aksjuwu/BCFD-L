<dash>
name: $var
desc: Reads or writes a temporary variable that lives only during the current script execution.
category: Variables

<block type="text" title="How does the command work?">
text: $var with one argument reads the variable's value. $var with two arguments writes a value to the variable. Temporary variables are cleared when the script finishes.
</block>

<block type="code" title="Syntax">
text: $var[name; value]
</block>

<block type="code" title="Ready-to-copy Example">
text: $var[score; 10]
$sendMessage[Your score is $var[score]]
</block>

<block type="callout" kind="note">
text: Unlike $setVar/$getVar (persistent), $var is only available during the current script run. It can be used inline inside other commands' arguments.
</block>
</dash>

<details>
syntax: $var[name; (value)]
param: name|text|Required|The variable name to read or write
param: value|text|Optional|If provided, writes this value to the variable (2-arg mode). If omitted, reads and returns the current value (1-arg mode).
</details>
