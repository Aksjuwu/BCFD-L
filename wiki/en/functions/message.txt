<dash>
name: $message
desc: Returns the arguments/words from the user's command message.
category: Info

<block type="text" title="How does the command work?">
text: When $message is called without arguments, it returns everything the user typed after the command name (the full argument string). When called with an index number, it returns the specific word at that position.
</block>

<block type="code" title="Syntax">
text: $message
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[You said: $message]
</block>

<block type="callout" kind="note">
text: Without arguments, returns all text after the command. With $message[1], returns the first word, $message[2] returns the second, and so on. Returns an empty string if the index is out of range.
</block>
</dash>
