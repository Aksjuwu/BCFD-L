<dash>
name: $boostCount
desc: Returns how many boost contributions the server currently has.
category: Server

<block type="text" title="How does the command work?">
text: $boostCount returns the server's current number of boosts (premium subscriptions). Without arguments it reads the server where the event occurred. You can pass any guild ID the bot shares to read another server's count.
</block>

<block type="code" title="Syntax">
text: $boostCount[(guildID)]
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[This server has $boostCount boosts!]
</block>

<block type="callout" kind="note">
text: This is the number of boosts, not the boost level - use $boostLevel for that.
</block>
</dash>

<details>
syntax: $boostCount[(guildID)]
param: guildID|snowflake|Optional|ID of the server whose boost count should be read (defaults to the current server)
</details>
