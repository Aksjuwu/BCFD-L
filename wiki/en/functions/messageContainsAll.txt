<dash>
name: $messageContainsAll
desc: Event triggered when a message contains ALL of the specified words.
category: Event

<block type="text" title="How does the event work?">
text: $messageContainsAll is an event prefix that triggers an FDScript only when a message contains ALL of the specified trigger words. Words are separated by semicolons inside the brackets. The match is case-insensitive.
</block>

<block type="code" title="Syntax">
text: #PREFIX:$messageContainsAll[word1;word2;word3]
</block>

<block type="code" title="Ready-to-copy Example">
text: #PREFIX:$messageContainsAll[bot;help]
 sendMessage[Need help with the bot? Here's how...]
</block>

<block type="callout" kind="note">
text: Unlike $messageContains, this requires ALL listed words to be present in the message. If any word is missing, the script will not run.
</block>

<block type="callout" kind="important">
text: This event runs in the bot_events folder, not bot_commands. Create your .fds file there.
</block>
</dash>

<details>
syntax: #PREFIX:$messageContainsAll[word1;word2;...]
param: words|text|Required|Semicolon-separated list of trigger words. ALL must match to trigger the script.
</details>
