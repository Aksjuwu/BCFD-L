<dash>
name: $channelType
desc: Returns the type of a channel (text, voice, category, forum, stage).
category: Channel

<block type="text" title="How does the command work?">
text: $channelType takes a channel mention or ID and returns the channel's type name as a string. Valid types include: text, voice, category, forum, stage. If no argument is provided, it returns the type of the current channel. Returns "unknown" if the channel cannot be found.
</block>

<block type="code" title="Syntax">
text: $channelType[channel mention/ID]
</block>

<block type="code" title="Ready-to-copy Example">
text: $channelType[<#123456789012345678>]
</block>

<block type="callout" kind="note">
text: Useful for validating channel types before executing type-specific operations like $createChannel or $voiceUsersLimit.
</block>
</dash>

<details>
syntax: $channelType[channel mention/ID]
param: channel|text|Optional|The channel mention or numeric ID. If empty, uses the current channel.
</details>
