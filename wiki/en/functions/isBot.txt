<dash>
name: $isBot
desc: Checks whether a user is a bot account.
category: Info

<block type="text" title="How does the command work?">
text: $isBot takes a user ID or mention and checks if that user is a Discord bot account. Returns "true" or "false".
</block>

<block type="code" title="Syntax">
text: $isBot[userID]
</block>

<block type="code" title="Ready-to-copy Example">
text: $isBot[$authorID]
</block>

<block type="callout" kind="note">
text: Returns "true" if the user is a bot account, "false" if they are a human user. The user must be a member of the server.
</block>
</dash>

<details>
syntax: $isBot[userID]
param: userID|text|Required|The user ID or @mention to check. Supports variables and placeholders.
</details>
