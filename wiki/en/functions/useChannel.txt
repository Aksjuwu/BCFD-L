<dash>
name: $useChannel
desc: Redirects all script output from this point onward to a specific channel in any server.
category: Access Control

<block type="text" title="How does the command work?">
text: $useChannel is executed in place, in the order the lines appear in the script. When the interpreter reaches it, it redirects the output of everything that follows (all $sendMessage, $sendEmbedMessage, $reply, buffered text, and so on) to the specified channel. Lines before it are unaffected.
</block>

<block type="code" title="Syntax">
text: $useChannel[guildID; channelID]
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[This goes to the current channel]
$useChannel[1234567890; 9876543210]
$sendMessage[This goes to the specified channel!]
</block>

<block type="callout" kind="note">
text: Both arguments are resolved before checking, but they must be numeric. The bot must be a member of the specified guild and be able to see the target channel. If the guild or channel is not found, or the arguments are not numeric, the command is silently ignored and a log entry is created.
</block>

<block type="callout" kind="warning">
text: Once set, the redirect applies to all subsequent output in the script — the original channel is no longer used. In a button interaction, the interaction response is deferred and later messages are sent to the target channel instead.
</block>
</dash>

<details>
syntax: $useChannel[guildID; channelID]
param: guildID|number|Required|The ID of the server (guild) where the target channel is located
param: channelID|number|Required|The ID of the channel to redirect all output to
</details>
