<dash>
name: $lastBotMessageID
desc: Returns the ID of the last message the bot sent during the current script.
category: Variables

<block type="text" title="How does the command work?">
text: $lastBotMessageID resolves to the snowflake ID of the most recent message the bot sent during the current script execution. It is updated automatically by output commands such as $sendMessage, $reply, and $sendEmbedMessage. If the bot has not sent any message yet, an empty string is returned.
</block>

<block type="code" title="Syntax">
text: $lastBotMessageID
text: $lastBotMessageID[]
</block>

<block type="code" title="Ready-to-copy Example">
text: $sendMessage[Look at this!]
$editIn[10s; The last message ID was $lastBotMessageID]
</block>

<block type="callout" kind="note">
text: This is an inline-only command and cannot be used as a standalone statement. Use it inside another command's argument brackets or as a bare inline token.
</block>
</dash>
