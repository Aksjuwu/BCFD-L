<dash>
name: $kick
desc: Kicks a user from the server.
category: Moderation

<block type="text" title="How does the command work?">
text: When $kick is called without arguments, it kicks the command author. When called with a user ID or mention, it kicks that specific user. The bot extracts the numeric user ID from the provided argument and issues a kick through the Discord API.
</block>

<block type="code" title="Syntax">
text: $kick
</block>

<block type="code" title="Ready-to-copy Example">
text: $kick[123456789]
</block>

<block type="callout" kind="warning">
text: The bot must have "Kick Members" permission and its highest role must be above the target's highest role. Using $kick without brackets will kick the user who triggered the command.
</block>
</dash>
