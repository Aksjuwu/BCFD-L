<dash>
name: $strictArgs
desc: Enforces a specific word count constraint on the user's command arguments.
category: Access Control

<block type="text" title="How does the command work?">
text: $strictArgs checks if the number of words the user provided matches the specified constraint. If the check fails, the error message is displayed and the script is aborted.
</block>

<block type="code" title="Syntax">
text: $strictArgs[comparison; error_message]
</block>

<block type="code" title="Ready-to-copy Example">
text: $strictArgs[>2; Please provide more than 2 words!]
</block>

<block type="options" title="Comparison operators">
option: >|Greater than — user must provide more than N words
option: <|Less than — user must provide fewer than N words
option: (none)|Equal to (e.g., just 2) — user must provide exactly N words
option: !|Not equal to — user must NOT provide exactly N words
</block>

<block type="callout" kind="note">
text: The word count excludes the command name itself. For example, if the user types "!cmd hello world", the word count is 2.
</block>
</dash>

<details>
syntax: $strictArgs[comparison; error_message]
param: comparison|text|Required|A constraint like >2, <2, 2, or !2 where the number is the required word count (plain 2 means exactly 2)
param: error_message|text|Required|Message displayed if the word count doesn't match the constraint
</details>
