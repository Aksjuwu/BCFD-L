<dash>
name: $onBotMessage
desc: Event triggered on every message sent by a bot (including other bots).
category: Event

<block type="text" title="How does the event work?">
text: $onBotMessage is an event prefix that triggers an FDScript whenever a bot sends a message. By default the script ignores messages sent by the bot itself and only reacts to other bots. Set the argument to yes to also run the script on the bot's own messages, or no to skip its own messages (this is also the default when the argument is empty).
</block>

<block type="code" title="Syntax">
text: #PREFIX:$onBotMessage[yes/no]
</block>

<block type="code" title="Ready-to-copy Example">
text: #PREFIX:$onBotMessage[no]
$sendMessage[Another bot said: $message]
</block>

<block type="callout" kind="note">
text: Use yes to follow the bot's own messages, or no to only react to other bots. The example above uses $message to read the bot message content.
</block>

<block type="callout" kind="important">
text: This event runs in the bot_events folder, not bot_commands. Create your .fds file there.
</block>
</dash>

<details>
syntax: #PREFIX:$onBotMessage[(yes/no)]
param: yes/no|text|Optional|yes to also run on the bot's own messages, no (default) to only react to other bots
</details>
