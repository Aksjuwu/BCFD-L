<dash>
name: $returnGuildChannelsID
desc: Returns a list of all channel IDs in the server.
category: Return Commands

<block type="text" title="How does the command work?">
text: When $returnGuildChannelsID is called, the bot collects the unique Discord channel IDs of all channels in the current server and stores them. The result can be retrieved later using the $return command.
</block>

<block type="code" title="Syntax">
text: $returnGuildChannelsID
</block>

<block type="code" title="Ready-to-copy Example">
text: $returnGuildChannelsID
$sendMessage[Total channels: $return[channelIDs]]
</block>

<block type="callout" kind="note">
text: This command only works inside a server. The collected IDs are stored internally and can be accessed via the $return command after execution.
</block>
</dash>
