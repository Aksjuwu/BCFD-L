<dash>
name: $color
desc: Sets the color of the embed being built.
category: Embed Builder

<block type="text" title="How does the command work?">
text: $color takes a hex color value or a named color and applies it to the current embed being constructed. The color appears as the embed's left-side accent bar.
</block>

<block type="code" title="Syntax">
text: $color[hex or name]
</block>

<block type="code" title="Ready-to-copy Example">
text: $color[#FF5733]
</block>

<block type="callout" kind="note">
text: You can use hex codes (e.g., #FF5733, FF5733) or named colors. This command only affects embeds sent after it is called.
</block>
</dash>

<details>
syntax: $color[hex or name]
param: hex or name|text|Required|A hex color code (e.g., #FF5733) or a named color to set the embed accent bar color
</details>
