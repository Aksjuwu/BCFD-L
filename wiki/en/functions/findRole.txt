<dash>
name: $findRole
desc: Finds a role by name, ID, or mention and returns its role ID.
category: Utility

<block type="text" title="How does the command work?">
text: $findRole looks up a role in the current server using a role mention, a numeric role ID, or a role name (the name match is case-insensitive). It returns the role's ID. Used on its own, the ID is sent to the channel; used inline, the ID is substituted directly into the surrounding text.
</block>

<block type="code" title="Syntax">
text: $findRole[name]
text: $findRole[roleID]
text: $findRole[@role]
</block>

<block type="code" title="Ready-to-copy Example">
text: $findRole[Moderators]
</block>

<block type="callout" kind="note">
text: This command can only be used inside a server. If no role is found, an error is returned.
</block>
</dash>

<details>
syntax: $findRole[query]
param: query|text|Required|A role mention, a role ID, or a role name to search for (case-insensitive)
</details>
