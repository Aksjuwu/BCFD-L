<dash>
name: $getUserStatus
desc: Returns the online status of a user in the server.
category: Info

<block type="text" title="How does the command work?">
text: When $getUserStatus is called without arguments, it returns the online status of the command author. When called with a user ID or mention, it returns that user's status. Returns "offline" if the user is not found or is not a member of the server.
</block>

<block type="code" title="Syntax">
text: $getUserStatus
text: $getUserStatus[(userID/mention)]
</block>

<block type="code" title="Ready-to-copy Example">
text: Your status is: $getUserStatus
</block>

<block type="callout" kind="note">
text: Possible return values are: online, idle, dnd, offline. This command only works inside a server (not in DMs) since Discord only provides status information for guild members.
</block>
</dash>

<details>
syntax: $getUserStatus[(userID/mention)]
param: userID/mention|text|Optional|The user ID or @mention to check. If omitted, checks the command author.
</details>
