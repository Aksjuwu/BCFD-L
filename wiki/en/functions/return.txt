<dash>
name: $return
desc: Retrieves a value stored by a $returnXxx command and sends it to the channel.
category: Variables

<block type="text" title="How does the command work?">
text: $return takes a variable name and looks up its value in the return variables storage. This storage is populated by commands like $returnGuildUsersID, $returnGuildChannelsID, etc. The retrieved value is sent to the channel.
</block>

<block type="code" title="Syntax">
text: $return[var]
</block>

<block type="code" title="Ready-to-copy Example">
text: $returnGuildUsersID
$sendMessage[User IDs: $return[userIDs]]
</block>

<block type="callout" kind="note">
text: If the variable name doesn't exist in the return storage, an error is returned. Make sure to call the appropriate $returnXxx command before using $return.
</block>
</dash>

<details>
syntax: $return[var]
param: var|text|Required|The name of the return variable to retrieve (e.g., userIDs, channelIDs, roleIDs)
</details>
