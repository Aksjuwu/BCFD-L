<dash>
name: $returnGuildEmojisID
desc: Collects emoji IDs from a guild, filtered by type, and stores them.
category: Return Commands

<block type="text" title="How does the command work?">
text: $returnGuildEmojisID gathers the IDs of custom emojis from the specified guild and stores them under a variable name, joined by the separator. The type filter chooses between all emojis, static ones (png) and animated ones (gif).
</block>

<block type="code" title="Syntax">
text: $returnGuildEmojisID[GuildID; type; var; separator]
</block>

<block type="code" title="Ready-to-copy Example">
text: $returnGuildEmojisID[$guildID; animated; animEmojis; ,]
text: $sendMessage[Animated emojis: $return[animEmojis]]
</block>

<block type="callout" kind="note">
text: Type accepts: all, static, animated. The bot must be a member of the target guild. The stored order is not guaranteed to match the server's emoji list.
</block>
</dash>

<details>
syntax: $returnGuildEmojisID[GuildID; type; var; separator]
param: GuildID|snowflake|Required|ID of the guild whose emojis are collected
param: type|text|Required|Filter: all, static or animated
param: var|text|Required|Variable name to store the result in (read back with $return[])
param: separator|text|Required|Separator between IDs (e.g., ,). Named separators work too: dot, com, apo, sem, colon
</details>
