<dash>
name: $getSplitOutLength
desc: Returns the number of elements in the split result of $splitIn.
category: String Utilities

<block type="text" title="How does the command work?">
text: $getSplitOutLength returns how many parts were produced by the last $splitIn call. It is useful to check whether there is enough data before using $splitOut. The value is sent to the channel or can be used inline.
</block>

<block type="code" title="Syntax">
text: $getSplitOutLength
</block>

<block type="code" title="Ready-to-copy Example">
text: $splitIn[apple,banana,cherry; ,]
$getSplitOutLength
</block>

<block type="callout" kind="note">
text: Returns "0" when no split was performed yet. The same value can be used inline, for example with $if.
</block>
</dash>

<details>
syntax: $getSplitOutLength
</details>
