<dash>
name: $while
desc: Repeats the enclosed code block as long as a condition remains true.
category: Flow Control

<block type="text" title="How does the command work?">
text: $while evaluates a condition before each iteration. If the condition is true, the loop body executes. This repeats until the condition becomes false or $break is encountered.
</block>

<block type="code" title="Syntax">
text: $while[condition]
</block>

<block type="code" title="Ready-to-copy Example">
text: $setVar[i; 0]
$while[$getVar[i] < 5]
  $sendMessage[Count: $getVar[i]]
  $setVar[i; $math[$getVar[i] + 1]]
$endwhile
</block>

<block type="callout" kind="warning">
text: Ensure your loop has a clear termination condition to avoid infinite loops. An infinite loop will hang the script indefinitely. Use $break to exit early.
</block>
</dash>

<details>
syntax: $while[condition]
param: condition|expression|Required|The condition to evaluate before each iteration. The loop continues while this is true. Uses the same operators as $if (==, !=, >, <, >=, <=).
</details>
