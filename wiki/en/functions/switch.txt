<dash>
name: $switch
desc: Selects and returns one item from a list based on an index number.
category: String Utilities

<block type="text" title="How does the command work?">
text: $switch takes a list of items and an index number (as the last argument). It returns the item at that position (1-based index). This is useful for selecting from predefined options.
</block>

<block type="code" title="Syntax">
text: $switch[item1; item2; ... ; index]
</block>

<block type="code" title="Ready-to-copy Example">
text: $switch[Red; Green; Blue; $randomint[1; 3]]
</block>

<block type="callout" kind="note">
text: The index is the LAST argument and must be a number between 1 and the total number of items. If the index is out of bounds, an error is returned.
</block>
</dash>

<details>
syntax: $switch[item1; item2; ... ; index]
param: item|text|Required|One or more items to choose from
param: index|number|Required|The 1-based position of the item to return (must be last argument)
</details>
