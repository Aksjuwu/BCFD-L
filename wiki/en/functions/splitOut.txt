<dash>
name: $splitOut
desc: Retrieves a specific part from a previously split text (using $splitIn).
category: String Utilities

<block type="text" title="How does the command work?">
text: $splitOut accesses a specific part of the split result from $splitIn. Use a 1-based index, < for the first part, or > for the last part. The retrieved value is sent to the channel.
</block>

<block type="code" title="Syntax">
text: $splitOut[index]
</block>

<block type="code" title="Ready-to-copy Example">
text: $splitIn[apple,banana,cherry; ,]
$splitOut[2]
</block>

<block type="callout" kind="note">
text: Valid index values: a number (1-based), < (first element), > (last element). $splitIn must be called before $splitOut.
</block>
</dash>

<details>
syntax: $splitOut[index]
param: index|text|Required|The index of the part to retrieve: a number (1-based), < for first, or > for last
</details>
