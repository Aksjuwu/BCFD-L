<dash>
name: $returnGuildRolesID
desc: Collects role IDs from a guild, optionally filtered by permission, and stores them.
category: Return Commands

<block type="text" title="How does the command work?">
text: $returnGuildRolesID collects role IDs from a specified guild, optionally filtering by a required permission. The result is stored under a variable name and can be retrieved later using $return[variableName]. If no permission filter is specified, all roles (except @everyone) are collected.
</block>

<block type="code" title="Syntax">
text: $returnGuildRolesID[GuildID; permission; var; separator]
</block>

<block type="code" title="Ready-to-copy Example">
text: $returnGuildRolesID[$guildID; all; roleIDs; ,]
$sendMessage[Roles: $return[roleIDs]]
</block>

<block type="callout" kind="note">
text: For the permission parameter: leave empty or use "all" to get all roles. You can also specify a named permission (e.g., kick_members, manage_messages) or a raw permission integer. Only roles that have the specified permission (or higher) will be included.
</block>

<block type="callout" kind="warning">
text: The bot must be a member of the target guild. The @everyone role is always excluded from the results.
</block>
</dash>

<details>
syntax: $returnGuildRolesID[GuildID; permission; var; separator]
param: GuildID|snowflake|Required|The ID of the guild (server) to collect roles from
param: permission|text|Required|Permission filter: leave empty or "all" for all roles, a named permission (e.g., kick_members), or a raw permission integer
param: var|text|Required|The variable name to store the result in (use with $return[])
param: separator|text|Required|The separator between multiple IDs (e.g., , or ;). You can use named separators: dot, com, apo, sem, colon
</details>
