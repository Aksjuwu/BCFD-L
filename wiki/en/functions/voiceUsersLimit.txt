<dash>
name: $voiceUsersLimit
desc: Returns the user limit of a voice or stage channel.
category: Channel

<block type="text" title="How does the command work?">
text: $voiceUsersLimit takes a voice or stage channel ID and returns its user limit. A value of 0 means there is no limit. Returns an error if the channel is not a voice/stage channel.
</block>

<block type="code" title="Syntax">
text: $voiceUsersLimit[voice channel ID]
</block>

<block type="code" title="Ready-to-copy Example">
text: $voiceUsersLimit[123456789012345678]
</block>

<block type="callout" kind="note">
text: Returns 0 if the channel has no user limit set. Can be used inline for conditional checks.
</block>
</dash>

<details>
syntax: $voiceUsersLimit[voice channel ID]
param: channelID|text|Required|The ID of a voice or stage channel.
</details>
