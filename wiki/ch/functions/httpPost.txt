<dash>
name: $httpPost
desc: 向 URL 发送带有可选请求体的 HTTP POST 请求。
category: HTTP

<block type="text" title="此命令如何工作？">
text: $httpPost 发送一个超时时间为 10 秒的 POST 请求。当请求体是有效的 JSON 时以 JSON 形式发送，否则以原始文本形式发送。响应存储到 $httpResult，状态码存储到 $httpStatus。使用 $httpAddHeader 添加的标头会被发送，随后清除。
</block>

<block type="code" title="语法">
text: $httpPost[URL; (Body)]
</block>

<block type="code" title="可直接复制的示例">
text: $httpAddHeader[Content-Type; application/json]
$httpPost[https://api.example.com/users; {"name": "FDScript"}]
$httpResult[id]
</block>

<block type="callout" kind="note">
text: 如果请求体是有效的 JSON，则作为 JSON 发送，否则作为原始数据发送。请求失败时，状态码设为 500，且 $httpResult 包含错误信息。
</block>
</dash>

<details>
syntax: $httpPost[URL; (Body)]
param: URL|text|Required|要发送 POST 请求的 URL
param: Body|text|Optional|请求体（JSON 或原始文本）
</details>
