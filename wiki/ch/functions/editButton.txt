<dash>
name: $editButton
desc: 编辑消息上现有按钮的属性。
category: 组件

<block type="text" title="命令如何工作？">
text: $editButton 通过按钮的 ID 或 URL 在消息上查找按钮，并更新其标签、样式、禁用状态和/或表情符号。它可以针对待处理视图、交互来源消息或按 ID 指定的特定消息上的按钮。
</block>

<block type="code" title="语法">
text: $editButton[ID/URL; label; style; (disabled; emoji; messageID)]
</block>

<block type="code" title="可复制示例">
text: $editButton[btn_confirm; Confirmed; success]
</block>

<block type="callout" kind="note">
text: 如果提供了 messageID，机器人会获取该特定消息并编辑其上的按钮。否则，它会依次搜索待处理视图、交互来源消息以及机器人发送的最后一条消息。
</block>

<block type="callout" kind="warning">
text: 目标消息必须是由该机器人发送的。具有给定 ID 或 URL 的按钮必须已经存在于消息上。
</block>
</dash>

<details>
syntax: $editButton[ID/URL; label; style; (disabled; emoji; messageID)]
param: ID/URL|text|Required|要编辑的按钮的自定义 ID 或 URL
param: label|text|Required|要在按钮上显示的新文本
param: style|text|Required|primary / secondary / success / danger / link
param: disabled|yes/no|Optional|yes 禁用该按钮，no 启用它
param: emoji|text|Optional|按钮内显示的新表情符号
param: messageID|snowflake|Optional|要在其上编辑按钮的特定机器人消息的 ID
</details>
